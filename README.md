# MATRIX · Markestrated

Web para los 22 integrantes de la lista: tres quizzes de diez preguntas, 20 segundos obligatorios por pregunta y selección de nombre sin temporizador.

Contenido: páginas físicas 1–20, 21–41 y 42–64 del Manual Markestrated. Las preguntas y las soluciones viven en el receptor, fuera de este repositorio público.

Las respuestas se guardan, una por una, en el repositorio privado `matiasbtt/matrix-markestrated-respuestas`. El navegador muestra confirmación solamente cuando GitHub confirma la escritura. Una interrupción permite reintentar el guardado; recargar no reinicia el tiempo de la pregunta. La página no recibe ni contiene credenciales de GitHub.

Plazo configurado: 24/10/2026 a las 18:00 de Bolivia. La recepción requiere que el propietario configure la credencial privada del receptor.
